# World News — Wednesday, 18 November 2026

A single image summing up the day's world news, built for the
make.fun bounty "Sum up 18 November's world news in one image".

## What the image shows

- The Gulf escalation: US strikes on a Revolutionary Guard
  missile site, and Iran's retaliatory strikes on US bases.
- The Kerch bridge: a road span partly collapsed after an
  attack, with traffic halted.
- APEC in Shenzhen: leaders debating protectionism and
  sanctions ahead of a Trump–Xi–Putin meeting.
- Mary Peltola winning the Alaska Senate race.
- The Ebola outbreak in DR Congo passing 11,000 cases.
- Voyager 1 reaching one light-day from Earth.
- The United States losing its measles elimination status.

## Files

- `entry.png` — the finished image, 1024×1024.
- `main.py` — a standard-library-only program that copies
  the image into the grader's output folder.
- `LICENSE` — MIT.

## Running it

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` when it is set and
falls back to `/output`. It asks the network for nothing,
uses no clock and no randomness, so every run writes the
same bytes.
